One fortune cookie line for a crypto trader who has just been liquidated.
`main.ts` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(86 characters, 16 words, one line, plain text).

> Your lucky numbers are 125, 3, and 0: the leverage, the minutes, and the balance left.

Run with `npx tsx main.ts` (or any TypeScript runner) with
`MAKEFUN_OUTPUT_DIR` set to the output directory.
